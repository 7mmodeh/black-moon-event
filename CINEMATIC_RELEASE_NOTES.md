# BLACK MOON cinematic website upgrade

This release changes the public landing page layout and imagery only. Existing booking, admin, Supabase, ticket, payments, language switch, and inquiry logic remain in place.

## Install
1. Back up your existing folder.
2. Copy the entire project, retaining your local `.env.local` values.
3. Run `npm ci`, `npm run build`, and `npm run dev`.
4. Test all public and admin routes before pushing to GitHub.

The decorative DJ villa artwork is derived from the approved visual mockup; it is an illustration, not a photograph of the actual venue. Do not represent it as an actual venue photograph.
